# 매장 검수 가이드

## 상태

- `pending`: 자동 추출되었고 아직 사람이 검토하지 않은 후보
- `verified`: 포함 기준을 충족한다고 사람이 확인한 매장
- `rejected`: 제외 기준에 해당한다고 사람이 확인한 후보
- `needs_recheck`: 필수값 누락, 좌표 문제, 중복 의심 또는 판단 근거 부족으로 추가 확인이 필요한 후보

앱에는 향후 `verified` 매장만 표시한다. Phase 2.1A에서는 상태를 사람이 변경하는 도구나 Flutter 반영을 구현하지 않는다.

## 수동 검수 항목

1. `sourceStoreId`, 상호명, 지점명이 원본 행과 같은지 확인한다.
2. 도로명주소와 좌표가 같은 실제 위치를 가리키는지 확인한다.
3. 현재 영업 중인 오프라인 매장인지 확인한다.
4. 버거가 주요 메뉴인지 확인한다.
5. 대형 체인, 팝업, 폐업, 배달 전문점 등 제외 기준에 해당하는지 확인한다.
6. 동일한 `sourceStoreId`, `candidateId`, 정규화된 매장명과 주소의 중복 경고를 확인한다.
7. 판단 근거와 확인일을 검수 메모에 기록한다.

## 자동 품질 경고

추출기는 다음 상황을 `needs_recheck`로 표시한다.

- 필수값 누락
- 숫자가 아니거나 허용 범위를 벗어난 위도·경도
- `(0, 0)` 좌표
- 넓게 설정한 서울 검수 경계 밖의 좌표
- `sourceStoreId` 또는 `candidateId` 중복
- 공백과 영문 대소문자를 정규화한 매장명·도로명주소 중복

30m 이내 유사 이름 검사는 이번 Phase에서 수행하지 않는다. 실제 후보의 중복 양상을 확인한 뒤 Phase 2.1B 검토 항목으로 남긴다.
