# 로컬 매장 즐겨찾기

## 범위

즐겨찾기는 현재 기기의 로컬 저장소에만 보관한다. 로그인, Supabase 쓰기, 서버 동기화,
사용자 추적은 추가하지 않았다. 공개 매장의 `StoreLocation.id`를 식별자로 사용하며,
Supabase 모드에서는 이 값이 내부 매장 UUID다. 이름이나 주소 변경은 즐겨찾기 식별에
영향을 주지 않는다.

## 저장 방식

`shared_preferences 2.5.5`의 `SharedPreferencesAsync`를 사용한다. 저장 키는
`favorite_store_ids_v1`이며 값은 중복을 제거하고 정렬한 매장 ID 문자열 목록이다.
앱 시작 시 목록을 다시 읽기 때문에 완전 종료 후에도 유지된다. 저장된 ID가 현재
`verified + active` 조회 결과에 없으면 지도와 결과 목록에서 안전하게 무시한다.

## 사용자 동작

- 매장 상세 화면의 별 아이콘으로 즐겨찾기를 추가하거나 해제한다.
- 지도 검색 영역의 `즐겨찾기` 필터로 즐겨찾기 매장만 본다.
- 즐겨찾기 조건은 매장명·주소 검색 및 버거 스타일 필터와 AND로 결합한다.
- 필터링은 이미 로딩된 매장에만 적용하며 Supabase 요청을 추가하지 않는다.
- 저장 실패 시 기존 상태를 유지하고 일반적인 재시도 안내를 표시한다.

## 자동 검증

- 상세 화면 추가·해제
- 동일 로컬 저장소를 사용한 앱 화면 재생성 후 복원
- 즐겨찾기·검색·버거 스타일 AND 결합
- 삭제되거나 비공개된 매장 ID 무시
- 기존 검색·필터·상세·길찾기 회귀

## 수동 확인

Android 에뮬레이터에서 공개 매장 한 곳을 즐겨찾기에 추가한 뒤 앱을 완전히 종료하고
재실행해 별 상태와 즐겨찾기 필터 결과가 유지되는지 확인해야 한다. 검색과 스타일
필터를 함께 적용했을 때 마커·결과 목록·상세 카드가 같은 조건을 따르는지도 확인한다.
