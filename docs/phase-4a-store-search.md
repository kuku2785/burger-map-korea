# Phase 4A 매장 검색

## 범위

Phase 4A는 지도 화면에 이미 로딩된 매장 목록을 매장명과 주소로 검색하는 로컬 필터 기능이다. 검색어 입력이나 결과 선택 시 Supabase 또는 외부 장소 API를 호출하지 않는다.

지원 데이터 모드는 기존과 같다.

- `pilot`: 이태원 파일럿 매장
- `staging`: development 전용 로컬 staging 매장
- `supabase`: development 전용 공개 매장 SELECT 결과

production/release 데이터 모드 차단 정책, Supabase RLS와 쿼리, DB migration은 변경하지 않는다.

## 검색 동작

검색 문자열과 매장명·주소는 비교할 때 다음 순서로 정규화한다.

1. 앞뒤 공백 제거
2. 영문 소문자 변환
3. 연속 공백을 한 칸으로 축소

정규화된 검색어가 매장명 또는 주소에 부분 문자열로 포함되면 결과에 표시한다. 원본 매장 데이터와 화면 표기는 변경하지 않는다.

- 빈 검색어: 로딩된 전체 매장과 마커 표시
- 검색어 입력: 일치하는 마커와 간결한 결과 목록만 표시
- 결과 없음: `검색 결과가 없습니다.` 표시
- 결과 선택: 키보드 닫기, 기존 상세 카드 표시, 해당 좌표로 카메라 이동
- 검색어 지우기: 전체 마커 복원, 결과 목록 닫기
- 선택 매장이 새 검색 결과에서 제외됨: 선택 상태 안전 해제

기존 마커 선택, 빈 지도 탭 선택 해제, 카메라 이동 이벤트, 로딩·빈 상태·오류·재시도 동작은 유지한다.

## 데이터와 비용

매장 목록은 화면 진입 시 기존 로더에서 한 번 가져온다. 검색 입력, 필터링, 결과 선택은 메모리의 `List<StoreLocation>`만 사용하므로 추가 Supabase SELECT와 추가 API 비용이 없다. Supabase의 빈 결과는 기존 `현재 공개된 매장이 없습니다.` 상태로 처리하며 다른 데이터 모드로 대체하지 않는다.

Flutter에는 INSERT, UPDATE, DELETE, UPSERT, RPC 또는 외부 검색 API 경로를 추가하지 않았다. 검색어와 검색 기록도 저장하지 않는다.

## UI와 접근성

- 지도 상단 검색창에 `매장 검색` label과 `매장명 또는 주소` hint 제공
- 검색 지우기 아이콘에 `검색어 지우기` tooltip 제공
- 결과 행은 최소 56 logical pixels 높이 유지
- 결과 목록 높이를 화면 높이에 따라 제한해 지도 조작 영역을 보존
- 긴 매장명과 주소는 제한된 줄 수에서 말줄임 처리

## 테스트 범위

- 매장명·주소 부분 검색
- 대소문자·앞뒤 공백·연속 공백 정규화
- 빈 검색어와 결과 없음
- 마커 필터링 및 검색 해제 후 복원
- 결과 선택 후 상세 카드와 카메라 이동 요청
- 필터에서 제외된 선택 매장 해제
- 검색 중 데이터 로더 1회 호출 유지
- pilot/staging/supabase와 빈 상태·오류·재시도 회귀
- 기존 마커 선택과 빈 지도 탭 선택 해제 회귀
- 작은 화면 결과 목록과 검색 지우기 접근성

## Android 수동 검증

2026-08-20 Android 에뮬레이터에서 `APP_ENV=development`,
`STORE_DATA_MODE=staging` 설정으로 사용자 수동 검증을 수행했다.

- staging 매장 24개 로딩 확인
- 검색창에 `PPS` 입력 후 PPS 검색 결과와 해당 마커만 표시되는지 확인
- Enter 입력은 매장을 선택하지 않고 검색 결과만 유지하는지 확인
- 검색 결과 행을 직접 누르면 카메라가 PPS 좌표로 이동하는지 확인
- 선택 후 기존 상세 카드에 매장명과 주소가 표시되는지 확인
- 검색 지우기 버튼을 누르면 전체 24개 마커가 복원되는지 확인
- `zzzz` 입력 시 `검색 결과가 없습니다.`가 표시되는지 확인

에뮬레이터의 한/영 키와 클립보드 입력 문제로 한국어 검색어 직접 입력은
수동 검증하지 못했다. 한국어 문자열 검색은 기존 자동 테스트 범위까지만
검증됐으며 Android 수동 검증 완료 항목으로 간주하지 않는다.

## Phase 4B와의 구분

Phase 4A는 텍스트 검색만 제공한다. 가격, 매장 유형, 주차 가능 여부 같은 구조화 필터는 데이터 필드와 검수 기준을 먼저 확정한 뒤 Phase 4B에서 별도로 설계한다. 마커 클러스터링, 검색 기록, 위치 권한, 서버 검색은 Phase 4A에 포함하지 않는다.
