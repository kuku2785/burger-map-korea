## 3. 위치 처리

사용자가 현재 위치 또는 가까운 순 기능을 선택하면 Android 위치 권한을 요청합니다. 권한을 거부해도 일반 매장 탐색을 계속할 수 있습니다. 대략적인 위치 권한만 허용한 경우에도 기능을 지원하며 정확도 안내를 표시합니다.

버거맵의 현재 위치 좌표는 앱 메모리에서 처리됩니다. 앱의 Supabase 요청, 데이터베이스 저장, SharedPreferences 저장 또는 자체 진단 로그에 이 좌표를 넣는 경로는 확인되지 않았습니다. 앱이 배경으로 전환되면 현재 위치 상태를 무효화합니다. OS가 관리하는 최근 위치를 읽을 수 있으며 이는 앱이 좌표 기록을 새로 저장한다는 뜻은 아닙니다.

Google Maps의 현재 위치 표시와 카메라 이동에는 위치 관련 정보가 전달됩니다. 따라서 “좌표가 어떠한 외부 서비스에도 전달되지 않는다”는 보장은 하지 않습니다. **TODO:** 현재 Maps/위치 SDK 버전에서 기기 밖으로 전송되는 위치 관련 항목과 보유 여부를 확정하여 공개본에 반영할 것.

길찾기를 선택하면 매장의 목적지 정보가 외부 Google Maps 앱 또는 웹으로 전달됩니다. 버거맵은 이 링크에 사용자의 현재 위치를 출발지로 첨부하지 않습니다. 외부 앱이 직접 취득하는 위치는 해당 서비스의 설정과 방침에 따릅니다.
